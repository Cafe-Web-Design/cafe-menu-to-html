# Try Cafe Menu Builder and share what would make it more useful

This free browser tool is for independent cafe owners. Turn your dishes, drinks and prices into a readable menu you can check, copy and print.

[Open the tool](https://cafe-web-design.github.io/cafe-menu-to-html/). No coding knowledge, installation or account is needed. Start with the fictional example, or fill in the labelled fields with your own information. A clean menu preview and a text file you can give to your website designer.

Feedback about unclear questions, missing practical options or mobile usability is welcome here. Please use fictional information in public examples and keep customer or confidential details out of this discussion.

Only use dietary and allergen wording your cafe has checked. The tool does not identify allergens or verify food information.

Maintained by [Cafe Web Design](https://cafewebdesign.uk/), operated by JW Digital Services Ltd. The original developer helpers are still available in the repository, but they are not needed to use the browser tool.
